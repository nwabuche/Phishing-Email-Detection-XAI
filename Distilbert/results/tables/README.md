# DistilBERT Experimental Results Tables

This folder contains the experimental results tables
for the DistilBERT phishing email detection model.

The tables present the baseline evaluation results,
SHAP-guided experimental results, and final model
performance.

The results include classification performance,
false-positive and false-negative counts, and
comparisons between the baseline and refined models.

All reported values are taken from the original
DistilBERT experiments.
