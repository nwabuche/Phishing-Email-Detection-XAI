# DistilBERT Experimental Figures

This folder contains the figures generated from the DistilBERT phishing email detection experiments.

The figures include:

1. Baseline confusion matrix.
2. Final model confusion matrix.
3. False-positive and false-negative comparison chart.
4. Receiver Operating Characteristic (ROC) curve.
5. SHAP feature importance visualization.

These figures support the evaluation and interpretation of the DistilBERT model.
