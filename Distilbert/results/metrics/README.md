# DistilBERT Performance Metrics

This folder contains the evaluation metrics obtained from the DistilBERT phishing email detection experiments.

The evaluation includes accuracy, precision, recall, F1-score, ROC-AUC, false positives, and false negatives.

The results document the performance of the baseline model, the SHAP-guided experimental stages, and the final refined model.

All reported metrics are based on the original experimental results.
