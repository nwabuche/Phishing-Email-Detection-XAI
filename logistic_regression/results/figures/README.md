# Logistic Regression — Experimental Figures

## Overview

This folder contains the figures used to present the results of my Logistic Regression experiments for phishing email detection.

The figures support my master's thesis, which investigates how explainability-guided feature analysis can reduce false positives without increasing false negatives.

## Figures

The planned figures include:

1. Baseline confusion matrix.
2. Final model confusion matrix.
3. Baseline and final false-positive and false-negative comparison.
4. ROC curve, when the required prediction data is available.

## Purpose

I use these figures to explain the classification performance of my models and show the effect of the explainability-guided intervention.

The baseline model produced 88 false positives and 48 false negatives. The final model reduced false positives to 79 while maintaining 48 false negatives.

All figures will be based on the recorded experimental results.
