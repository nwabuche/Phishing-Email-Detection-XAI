# Logistic Regression Baseline Results

This directory contains the evaluation results of the official Logistic Regression baseline model for phishing email detection.

The baseline model was evaluated on 10,716 test emails using Term Frequency-Inverse Document Frequency (TF-IDF) features.

The model achieved an accuracy of 98.73%, with 88 False Positives and 48 False Negatives.

These results provide the reference for evaluating the effectiveness of the SHAP-informed corrective approach.
